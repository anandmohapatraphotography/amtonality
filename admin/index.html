Editor access

To publish edits to your site, this editor needs a GitHub personal access token — think of it as the password for the editor.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: anything like amtonality-editor
  3. Expiration: 1 year (or longer)
  4. Repository access: Only select repositories → amtonality
  5. Repository permissions: Contents → Read and write. Metadata → Read (auto).
  6. Click Generate token, copy it (starts with github_pat_), paste below.

The token is stored only in your browser (localStorage). No server sees it. You can clear it any time by clearing site data.
